What is IFSC Code? (पूरी जानकारी हिंदी में)

IFSC code भारत में हर bank branch को identify करने का एक unique code है। अगर आप online money transfer करते हैं — NEFT, RTGS, IMPS या UPI — तो आपको हर बार IFSC code की जरूरत पड़ती है।

लेकिन बहुत लोगों को पता ही नहीं होता कि IFSC code में क्या-क्या होता है, यह कहाँ मिलता है, और कैसे use होता है। इस guide में हम सब कुछ detail में समझेंगे।

Quick Answer: IFSC का full form है Indian Financial System Code. यह 11 characters का alphanumeric code होता है जो हर bank branch को uniquely identify करता है। RBI ने इसे NEFT, RTGS और IMPS जैसे electronic payment systems के लिए standardize किया है।

IFSC Code की Full Form और Meaning

IFSC = Indian Financial System Code.

यह code Reserve Bank of India (RBI) ने develop किया है, और National Payments Corporation of India (NPCI) इसे manage करता है। इसका main purpose है — हर bank branch को एक unique identity देना, ताकि electronic fund transfer में कोई गलती न हो।

जब आप किसी को पैसे भेजते हैं, तो system को पता होना चाहिए कि पैसे किस bank की किस branch में जाने हैं। यही काम IFSC code करता है।

IFSC Code की Structure — 11 Characters का मतलब

IFSC code 11 characters का होता है, जो तीन parts में बँटा होता है:

Example: HDFC0004349

HDFC = Bank Code (पहले 4 characters)
0 = Fixed Zero (5वाँ character)
004349 = Branch Code (आखिरी 6 characters)

1. पहले 4 Characters — Bank Code

ये characters bank का नाम दर्शाते हैं। हर bank का अपना code होता है:

  • HDFC — HDFC Bank
  • SBIN — State Bank of India
  • ICIC — ICICI Bank
  • UTIB — Axis Bank
  • PUNB — Punjab National Bank

2. 5वाँ Character — हमेशा "0"

यह character हमेशा zero (0) होता है। यह RBI ने future use के लिए reserve किया है। अभी तक इसका कोई specific purpose नहीं है, लेकिन rule यही है — 5वाँ character हमेशा 0 होगा।

3. आखिरी 6 Characters — Branch Code

ये characters specific branch को identify करते हैं। यह हर branch के लिए अलग होता है, चाहे वो same bank की ही क्यों न हो।

Zaruri baat: एक ही bank की दो different branches के IFSC code में पहले 4 characters same होंगे, लेकिन आखिरी 6 characters अलग होंगे।

IFSC Code कहाँ-कहाँ मिलता है?

आप अपने bank का IFSC code इन जगहों से पा सकते हैं:

  1. Cheque Book — हर cheque के top-left corner में IFSC code printed होता है, bank के नाम और address के ऊपर।
  2. Passbook — passbook के पहले page पर, account details के साथ।
  3. Online Banking — net banking या mobile banking app में account details देखें।
  4. Bank Statement — हर statement पर branch details के साथ IFSC code होता है।
  5. IFSC India — हमारी website पर IFSC code search करके भी पता कर सकते हैं।

IFSC Code का Use कहाँ होता है?

IFSC code इन सभी electronic payment systems में use होता है:

System Full Form Use
NEFT National Electronic Funds Transfer Bank to bank money transfer (₹1 से शुरू)
RTGS Real Time Gross Settlement High-value transfer (₹2 लाख+)
IMPS Immediate Payment Service Instant transfer 24x7 (₹5 लाख तक)
UPI Unified Payments Interface Mobile-based instant payment

इन सभी में IFSC code की जरूरत पड़ती है — ताकि system को पता चले कि पैसे किस branch में भेजने हैं।

IFSC Code और MICR Code में फर्क

बहुत लोग IFSC और MICR को confuse कर देते हैं। दोनों अलग हैं:

Feature IFSC Code MICR Code
Length 11 characters 9 digits
Type Alphanumeric (A-Z, 0-9) सिर्फ numbers (0-9)
Use NEFT, RTGS, IMPS, UPI Cheque clearing
Kahan milta hai Cheque के ऊपर, passbook में Cheque के नीचे

आसान भाषा में: IFSC digital payment के लिए, MICR physical cheque के लिए।

IFSC Code कैसे Search करें?

अगर आपके पास किसी bank branch का IFSC code है और आप उसकी पूरी details चाहते हैं, तो आप IFSC India पर search कर सकते हैं।

बस 11-character IFSC code डालें (जैसे HDFC0004349) और आपको मिल जाएगा:

  • Bank का नाम
  • Branch का नाम
  • पूरा address
  • City, District, State
  • Contact number
  • MICR code
  • SWIFT code (international transfers के लिए)
  • UPI, NEFT, RTGS, IMPS की availability

आप MICR code (9 digits) से भी search कर सकते हैं।
