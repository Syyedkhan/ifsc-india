Frequently Asked Questions

IFSC (Indian Financial System Code) is an 11-character alphanumeric code used to identify bank branches in India. It is used for NEFT, RTGS, IMPS and UPI transactions.
IFSC is an 11-character code used for online transactions (NEFT, RTGS, IMPS, UPI). MICR is a 9-digit numeric code printed on cheques for faster cheque processing.
SWIFT code is an 8 or 11-character code used for international money transfers between banks. It is also known as BIC.
