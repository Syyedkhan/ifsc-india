Frequently Asked Questions

IFSC (Indian Financial System Code) is an 11-character alphanumeric code used to identify bank branches in India. It is used for NEFT, RTGS, IMPS and UPI transactions. First 4 characters represent the bank, 5th character is always "0", and last 6 characters represent the branch.
The IFSC code is printed on the top-left corner of every cheque leaf, just above the bank branch address. It is also printed on the first page of your bank passbook.
IFSC is an 11-character alphanumeric code used for online electronic transactions (NEFT, RTGS, IMPS, UPI). MICR is a 9-digit numeric code printed on cheques using magnetic ink for faster cheque processing. IFSC is used for digital payments, MICR for physical cheque clearing.
The MICR code is printed at the bottom of a cheque leaf, along with the cheque number. It is a 9-digit number printed in a special magnetic ink font.
SWIFT (Society for Worldwide Interbank Financial Telecommunication) code is an 8 or 11-character code used for international money transfers between banks. It is also known as BIC (Bank Identifier Code). SWIFT is used for foreign remittances, while IFSC is used for domestic transactions.
To transfer money via NEFT, RTGS, IMPS or UPI, you need to provide the recipient's IFSC code along with their account number. The IFSC code tells the banking system exactly which bank branch the money should be transferred to.
